Миний жижигхэн веб танилцуулгын хуудас

👩‍💻 Миний тухай

Намайг Эрдэнэболор гэдэг. Би мэдээллийн технологи, веб хөгжүүлэлт болон шинэ технологиудыг сонирхон судалж байгаа оюутан.

Би шинэ зүйл сурч, өөрийн гараар туршиж үзэх дуртай. Энэхүү веб хуудсыг HTML ашиглан өөрийн санаагаар бүтээж байна.

🌱 Миний сонирхол

  • Веб хөгжүүлэлт
  • Шинэ технологи судлах
  • Компьютер программ хангамж
  • Бүтээлч санаа боловсруулах
  • Шинэ зүйл туршиж сурах

💻 Миний эзэмшиж буй чадварууд

  • HTML5 үндэс
  • CSS-ийн анхан шатны ойлголт
  • Git болон GitHub ашиглах
  • C++ программчлалын үндэс
  • VS Code ашиглан код бичих

📚 Одоогоор сурч байгаа зүйлс

  1. HTML веб хуудас бүтээх
  2. Git ашиглан кодын хувилбар удирдах
  3. GitHub дээр төсөл байршуулах
  4. GitHub Pages ашиглан веб нийтлэх

🚀 Миний зорилго

Веб хөгжүүлэлтийн мэдлэгээ шат дараатайгаар нэмэгдүүлж, цаашдаа өөрийн сонирхол, санаагаа веб төсөл болгон хэрэгжүүлж сурах нь миний зорилго.

"Өдөр бүр бага ч гэсэн шинэ зүйл суръя."

🌐 Миний анхны веб төсөл

Энэхүү хуудас бол миний веб хөгжүүлэлтийн хичээл дээр хийж байгаа анхны HTML төсөл юм.

Миний дараагийн зорилго бол энэ хуудсыг улам хөгжүүлж, илүү олон веб төсөл нэмэх юм.
